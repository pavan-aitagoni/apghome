# APG-official

A clean, responsive, executive showcase gallery featuring curated web creations by APG.

Built using pure vanilla HTML5, CSS3, and JavaScript (zero frameworks, zero build tools).

---

## Featured Web Creations

1. **URjoydrop** — [https://wishdrop-six.vercel.app/](https://wishdrop-six.vercel.app/)  
   *Create and share personalized interactive digital surprises and celebratory greeting experiences.*

2. **cineportal** — [https://cineportal.online/](https://cineportal.online/)  
   *Discover movie, anime, manga, and global entertainment streaming platforms worldwide.*

3. **promp-ts** — [https://prompts-pearl.vercel.app/](https://prompts-pearl.vercel.app/)  
   *Explore a curated visual discovery gallery of AI image prompts, reel modes, and artistic styles.*

---

## Visual Direction & Palette

Designed with an executive Statesman Navy & Copper palette (matte finish, zero glow, zero neon):
- **Deep Navy** (`#0B1F3A`): Background with subtle atmospheric depth.
- **Card Surface** (`#112746`): Elevated matte container surface.
- **Cool Porcelain** (`#E9EEF3`): Primary typography and brand text.
- **Pale Steel** (`#C9D3DD`): Subtitles, domains, descriptions, and placeholder text.
- **Slate Steel** (`#3A5A80`): Hairline dividers, card outlines, and secondary borders.
- **Copper** (`#B5653A`): Primary CTA buttons and accent focus states.
